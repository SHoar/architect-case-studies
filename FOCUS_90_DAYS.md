# 90-day focus rule

**Rule:** Do not start net-new product domains for 90 days from 2026-10-13.

Finish and *narrate* the Architect Trilogy. New experiments are allowed **only** if they strengthen:

1. Agent evals / observability
2. MCP or skill boundaries for safe tooling
3. Platform reliability (IDP golden path, SLOs, verify scripts)

## In scope

- Publish and refine case studies in this repo
- Public surface: GitHub bio, pins, portfolio Architecture Notes
- Eval harness demo, SLO writeup, BFF+GitOps RFC
- One talk proposal (RVNUG / Carolina Codes)
- Golden-path docs so another engineer can run IDP lite or the eval demo in &lt;30 minutes

## Out of scope (park it)

- New fintech / wedding / LMS / geo / crypto product starts
- Forking another AI coding assistant “to explore”
- Broader language tourism unrelated to the trilogy

## Exit criteria (day 90)

- [ ] Trilogy case studies linked from portfolio + pinned on GitHub
- [ ] At least one live demo path documented (eval harness or IDP lite)
- [ ] Proof pack used in ≥1 interview or talk abstract
- [ ] No new domain repos created unless they map to the three allowed buckets above
